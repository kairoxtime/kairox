# KAIROX — Proposals Directory  
Standardized Space for Submitting Governance and Mission Proposals

---

## Purpose of This Folder
This directory contains all proposals submitted to the KAIROX ecosystem.  
Proposals may include:

- Humanitarian mission proposals  
- Governance improvements  
- Operational changes  
- Treasury-related requests  
- Any initiative requiring community review or approval  

All proposals must follow the official KAIROX Proposal Template.

---

## How to Submit a Proposal
1. Copy the official template:  
   → [KAIROX_PROPOSAL_TEMPLATE.md](./KAIROX_PROPOSAL_TEMPLATE.md)

2. Review the governance rules:  
   → [GOVERNANCE_FRAMEWORK.md](./GOVERNANCE_FRAMEWORK.md)

3. Create a new file inside this folder using the following naming convention:  
   `proposal-short-title-YYYY-MM-DD.md`  

   **Examples:** `proposal-water-filters-2026-01-10.md`  
   `proposal-governance-update-2026-02-01.md`

4. Fill out the template completely.

5. Commit the file to this folder.

6. Notify the KAIROX governance team for review.

---

## Proposal Lifecycle
A proposal typically moves through the following stages:

1. Draft — Submitted by the author  
2. Review — Evaluated by governance maintainers  
3. Vote — Community or council decision  
4. Approved / Rejected — Final status  
5. Archived — Moved to /proposals/archive after completion or rejection  

Archive folder:  
→ [proposals/archive](./archive)
