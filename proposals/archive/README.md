# KAIROX — Proposals Archive  
Historical Record of Governance and Mission Proposals

---

## Purpose of This Directory
This directory contains all archived proposals submitted to the KAIROX governance system.  
It ensures long‑term transparency, accountability, and traceability of all decisions made by the community and governance maintainers.

Archived proposals include:

- Approved proposals  
- Rejected proposals  
- Withdrawn proposals  
- Superseded proposals  

---

## Archival Criteria
A proposal is archived when:

- A final decision has been made (approved, rejected, or withdrawn)  
- The proposal has been superseded by a newer version  
- The execution of an approved proposal has been completed  
- The proposal is no longer active or under review  

---

## Directory Structure
```
/proposals/archive/
    proposal-short-title-YYYY-MM-DD.md
```

Each archived proposal file must follow the naming convention defined in the Proposals Directory.
