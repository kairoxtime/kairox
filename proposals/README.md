# KAIROX — Proposals Directory  
Official Repository for Governance and Mission Proposals

---

## Purpose of This Directory
This directory contains all active proposals submitted to the KAIROX governance system.  
It serves as the central hub for:

- Mission proposals  
- Governance proposals  
- Operational proposals  
- Treasury proposals  
- Proposal discussions and revisions  
- Links to archived proposals  

All proposals must follow the institutional standards defined in the Governance Framework and use the official proposal template.

---

## Proposal Requirements
Every proposal must include:

- Clear title and purpose  
- Problem statement  
- Proposed solution  
- Expected impact  
- Risks and mitigations  
- Budget (if applicable)  
- Timeline  
- Responsible parties  
- Verification plan (for missions)  

Proposals must be written using the official template:  
→ [KAIROX_PROPOSAL_TEMPLATE.md](/KAIROX_PROPOSAL_TEMPLATE.md)

---

## Naming Convention
All proposal files must follow this format:

```
proposal-short-title-YYYY-MM-DD.md
```

Examples:
```
proposal-water-filtration-2026-01-10.md
proposal-governance-update-2026-02-03.md
proposal-treasury-allocation-2026-03-15.md
```

This ensures consistency, traceability, and auditability.

---

## Directory Structure
```
/proposals/
    README.md
    archive/
```

### `/proposals/`
Contains:
- Active proposals  
- Proposals under review  
- Proposals pending vote  
- Proposals awaiting execution  

### `/proposals/archive/`
Contains:
- Approved proposals  
- Rejected proposals  
- Withdrawn proposals  
- Superseded proposals  

Archived proposals remain permanently accessible for transparency and governance integrity.

---

## Proposal Lifecycle
1. **Draft** — Author prepares proposal using the official template  
2. **Review** — Governance Maintainers evaluate completeness and alignment  
3. **Vote** — Proposal enters the decision-making process  
4. **Decision** — Approved, rejected, or deferred  
5. **Execution** — If approved, mission or change is implemented  
6. **Archive** — Proposal is moved to `/proposals/archive/`  

Full lifecycle details:  
→ [Governance Framework](/GOVERNANCE_FRAMEWORK.md)
