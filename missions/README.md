# KAIROX — Missions Directory  
Official Repository for Humanitarian Mission Documentation

---

## Purpose of This Directory
This directory contains all mission‑related documentation within the KAIROX ecosystem.  
It provides a transparent and auditable record of:

- Active missions  
- Completed missions  
- Mission proposals  
- Impact reports  
- Verification evidence  
- Post‑mission audits  

All mission activity must follow the institutional process defined in:  
→ [MISSION_PROCESS.md](/MISSION_PROCESS.md)

---

## Structure
```
/missions/
    README.md
    archive/
```

### `/missions/`
Contains:
- Mission proposals (linked from `/proposals/`)
- Execution logs (if applicable)
- Impact reports
- Verification materials

### `/missions/archive/`
Contains:
- Completed missions
- Rejected missions (if applicable)
- Historical mission records
