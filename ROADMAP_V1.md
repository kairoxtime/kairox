# KAIROX — Roadmap v1  
*A structured development plan for the humanitarian blockchain initiative.*

---

## 1. Overview  
This roadmap outlines the phased development of the KAIROX ecosystem. It is designed to ensure transparency, responsible growth, and alignment with the project’s humanitarian mission. Each phase builds on the previous one, ensuring long‑term sustainability and operational clarity.

For governance details, see the [Governance Framework](./GOVERNANCE_FRAMEWORK.md).  
For mission execution, see the [Mission Process](./missions/MISSION_PROCESS.md).

---

## 2. Phase 1 — Foundation (Completed / In Progress)  
**Objectives:**

- Establish the humanitarian mission  
- Deploy initial token (KRX) on Solana  
- Build the core community  
- Publish foundational documentation  
- Begin early humanitarian actions  
- Launch official communication channels  

**Deliverables:**

- Whitepaper v1  
- Roadmap v1  
- Governance Framework  
- Legal Disclaimer  
- Repository structure  
- Initial impact reports  

---

## 3. Phase 2 — Treasury Formation  
**Objectives:**

- Build the initial operational treasury  
- Document all treasury inflows transparently  
- Prepare multisig structure  
- Establish treasury rules and spending limits  

**Deliverables:**

- Multisig configuration  
- Treasury Policy  
- Public treasury dashboard  
- Reporting templates  

---

## 4. Phase 3 — Community Governance Activation  
**Objectives:**

- Enable community voting  
- Publish proposal templates  
- Begin structured governance cycles  
- Introduce working groups  

**Deliverables:**

- Proposal system  
- Proposal templates  
- Governance cycles  
- Contributor guidelines  

See the [Proposals Overview](./proposals/PROPOSALS_OVERVIEW.md).

---

## 5. Phase 4 — Token Migration Vote (If Approved)  
**Objectives:**

- Conduct a 72‑hour community vote  
- Decide whether to migrate from KRX to KRX2  
- Ensure transparency and fairness  

**Deliverables:**

- Migration proposal  
- Snapshot of holders  
- Public voting results  
- Migration plan  

---

## 6. Phase 5 — KRX2 Deployment (If Approved)  
**Objectives:**

- Deploy KRX2 on Solana  
- Assign mint and freeze authority to multisig  
- Prepare 1:1 swap  
- Document all transactions  

**Deliverables:**

- KRX2 contract  
- Swap interface  
- Migration report  
- Updated documentation  

---

## 7. Phase 6 — Staking & Rewards (KRX2 Only)  
**Objectives:**

- Introduce staking mechanisms  
- Implement impact‑aligned rewards  
- Launch long‑term holder incentives  

**Deliverables:**

- Staking program  
- Rewards framework  
- Public dashboards  

---

## 8. Phase 7 — Humanitarian Expansion  
**Objectives:**

- Scale partnerships  
- Increase mission frequency  
- Expand geographic reach  
- Publish verified impact reports  

**Deliverables:**

- Mission reports  
- Partner onboarding  
- Impact dashboards  

See the [Impact Report Template](./IMPACT_REPORT_TEMPLATE.md).

---

## 9. Phase 8 — Institutionalization  
**Objectives:**

- Establish KAIROX as a global humanitarian foundation  
- Formalize governance  
- Expand contributor base  
- Strengthen long‑term sustainability  

**Deliverables:**

- Foundation structure  
- Annual reports  
- Governance upgrades  
- Ecosystem expansion  

---

## 10. Roadmap Evolution  
This roadmap is a living document.  
Updates will be published as the project evolves and as the community approves new initiatives.
